Name:           ZoomBMP
Description:    Bitmap zoom sample in PM
Date:           2026-09-07
Version:        1.02
----------------------------

DESCRIPTION
-----------
This is a PM sample application that demonstrates zooming in and out of a
bitmap using GpiWCBitBlt with calculated source and target rectangles.

Left mouse button click  -- zoom in  (doubles magnification)
Right mouse button click -- zoom out (halves magnification)

The title bar displays the current zoom percentage.

Originally by John Webb / IBM Corp, 1993.


REQUIREMENTS
------------
- yum install git gcc make libc-devel binutils watcom-wrc watcom-wlink-hll watcom-wcc


COMPILE INSTRUCTIONS
--------------------
The source code is in the src/ directory. Two toolchains are supported.

GCC / kLIBC:
1) Ensure the EMXOMFLD variables are set (compile_gcc.cmd handles this):
     SET EMXOMFLD_LINKER=wl.exe
     SET EMXOMFLD_TYPE=WLINK
     SET EMXOMFLD_PRELINK=0
2) Run compile_gcc.cmd
   Output: bin-gcc\zoombmp.exe
   Log:    make_gcc.out

OpenWatcom:
1) Ensure the Watcom headers and libraries are in INCLUDE and LIB
   (compile_wat.cmd sets these from C:\watcom).
2) Run compile_wat.cmd
   Output: bin-wat\zoombmp.exe
   Log:    make_wat.out

TROUBLESHOOT
------------
If the build fails, check the log file (make_gcc.out or make_wat.out) for
details. The compile_*.cmd scripts run a clean step before building to ensure
stale object files do not hide errors.
